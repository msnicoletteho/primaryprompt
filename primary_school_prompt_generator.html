Teacher Dashboard Setup & SLS Embedding Guide

💡 How Teacher Dashboards Work in Standalone HTML Apps

When you generate an HTML game or deck with a Teacher Dashboard using AI, the generated single-file web app includes both the Student View and a Protected Teacher Analytics Panel.

1 Option A: Password-Protected Local Storage (Zero Setup Needed)

Easiest for SLS

The app automatically saves student scores, completion status, and question attempt counts in the web browser's localStorage.

  • How Teacher Accesses: Click the 🔒 Teacher Mode button at the top right of the generated app and enter your passcode (default: teacher123).
  • Features: Class summary stats, misconception breakdown, list of student names, and an "Export Results to CSV" button to open in Excel/Google Sheets.

2 Option B: Google Sheets Web App Endpoint (Live Cross-Device Data)

Live Analytics

Track scores across multiple student iPads or laptops in real-time into a single Google Sheet.

  1. Create a new Google Sheet. Go to Extensions > Apps Script.
  2. Paste this lightweight Google Apps Script:

Embedding into Singapore Student Learning Space (SLS)

1. Save the generated prompt code into a file named index.html.

2. Zip the file into activity.zip.

3. In SLS, add a HTML5 Component and upload the zip file. The audio read-aloud and dashboard will function seamlessly inside SLS!
